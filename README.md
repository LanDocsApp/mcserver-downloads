# McServer downloads

Downloads for **McServer** — run a Minecraft server on your own PC and let
friends join without port forwarding.

**[Get the latest version](../../releases/latest)**

The application source lives in a separate repository. This one only hosts
release files.

## Windows

Download the `-win-x64.zip`, unzip it somewhere permanent, and double-click
`start.bat`. Nothing else to install — Node.js is bundled.

## Mac / Linux

Use the small cross-platform zip from the download page. It needs
[Node.js](https://nodejs.org/en/download) installed.
